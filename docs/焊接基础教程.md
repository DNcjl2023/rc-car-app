# 焊接基础教程（新手向）

## 一、工具认识

- **电烙铁**：建议可调温 350°C 左右；固定瓦数的选 40W 左右
- **焊锡丝**：买"含松香芯"的（焊接时自动助焊），直径 0.8mm 左右最好用
- **烙铁架**（必须）：放热烙铁，别放桌上
- **湿海绵 / 铜丝球**：清洁烙铁头用
- **助焊剂**（可选）：新手别用，焊锡丝自带就够

## 二、安全第一（重要）

1. 烙铁头 **300°C+**，会烫伤、烫穿塑料/线皮，**别碰烙铁头**
2. 焊接时**通风**（开窗或风扇），焊锡冒的烟别吸
3. 烙铁用完**放回烙铁架**，拔电冷却后再收
4. **别焊电池**（18650 焊接有爆炸风险！电池用电池盒/焊片）

## 三、焊接五步（核心）

1. **预热**：烙铁插电等 3~5 分钟
2. **清洁**：烙铁头在湿海绵上擦，擦到亮银色
3. **上锡**：烙铁头挂一点焊锡（保护烙铁头、导热好）
4. **焊接**（关键手法）：
   - 烙铁头**同时接触焊盘和线/元件脚**，加热 1~2 秒
   - **焊锡丝送到接口处**（不是送到烙铁头上），让它自己融化流进接口
   - 焊锡流满接口后，**先撤焊锡丝，再撤烙铁**
   - 保持不动 1 秒，让焊点凝固
5. **检查**：焊点**光亮、饱满、像小锥子** = 合格

## 四、焊点好坏判断

| 状态 | 样子 | 处理 |
|---|---|---|
| ✅ 好 | 光亮、锥形、包裹紧密 | 完成 |
| ❌ 虚焊 | 灰暗、圆球、没融合 | 重新加热 + 补一点锡 |
| ❌ 桥接 | 相邻引脚连在一起（焊锡短路） | 用烙铁头把多余的锡带走/分开 |
| ❌ 过多/过少 | 一大坨 或 没包住 | 吸锡/补锡 |

## 五、本项目实操注意

1. **先练手**：拿几根废线、旧元件/废板子练 20 分钟，手感对了再焊关键件
2. **焊线到 L298N**：L298N 端子/排针焊盘大，好焊；先把线头剥 5mm、拧紧、上一点锡（"预镀锡"），再焊到端子
3. **ESP32-CAM 引脚**：GPIO12-15 引脚小，**小心别桥接**（相邻连锡）；焊完用万用表蜂鸣档查 IN1~IN4 对 GND 有没有短路（见万用表教程）
4. **18650 电池**：**不要直接焊**，用电池盒/点焊片
5. **GPIO12 下拉电阻**：如果要加，把 10K 电阻一端焊到 GPIO12、另一端焊到 GND 走线

## 六、常见新手坑

- 烙铁头不清洁 → 不上锡、导热差（勤擦海绵）
- 加热太久 → 烫坏线皮/元件（每点 2~3 秒内搞定）
- 焊锡丝往烙铁头上送 → 焊点一大坨（往接口处送）
- 烙铁头干烧 → 氧化发黑（不用时挂锡保护）
