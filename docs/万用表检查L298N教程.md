# 万用表检查 L298N 教程（新手向）

## 一、认识万用表（先花 1 分钟）

- **表笔**：黑笔插 `COM`，红笔插 `VΩmA`（测电压/电阻/通断都用这个口）
- **转盘档位**：
  - `DCV`（直流电压，标 V 或 V⎓）：测电池、供电
  - `Ω`（电阻）：测电机
  - `蜂鸣档`（喇叭/二极管图标）：测通断、查短路
- **读数**：液晶屏显示的数字就是结果

## 二、测电压（练习 + 检查供电）

1. 转盘打到 **DCV 20V** 档
2. 红笔碰正极（+），黑笔碰负极（−）
3. 读数字

**检查点：**
| 测量位置 | 预期 | 说明 |
|---|---|---|
| 18650×2 串联输出 | 7.4~8.4V | 新充电约 8.4V，用一段约 7.4V |
| L298N 的 VMS-GND | 电池电压（7.4V 左右） | 电机电源输入 |
| **L298N 的 VCC-GND** | **约 5V** | **核心！5V 稳压正常才能给 ESP32 用** |
| 4×AA 南孚输出 | 约 6V | 这就是之前 5V 稳压不够的原因 |

## 三、测通断 / 查短路（蜂鸣档）

转盘打到**蜂鸣档**，两表笔碰被测两点：
- **蜂鸣 = 通（短路/连通）**
- **不响 = 断开**

**检查点：**
1. **ENA / ENB 跳线帽**：表笔碰跳线帽两端金属 → 蜂鸣 = 短接（正常，使能开启）
2. **焊接前查短路**（重点！）：
   - IN1、IN2、IN3、IN4 各自对 GND：**不应蜂鸣**（蜂鸣 = 焊接短路）
   - OUT1~OUT4 对 GND：**不应蜂鸣**
   - **VMS(12V) 对 GND：绝不应蜂鸣**（响了 = 供电短路，危险！）

## 四、测电机（电阻档）

转盘打到 **Ω 200** 档，两表笔碰电机两根线：
- 直流电机一般 **几 Ω ~ 几十 Ω**（正常）
- 0 Ω = 线圈短路（坏）
- 无穷大（1 或 OL）= 断路（坏）

## 五、安全注意事项

1. **测电阻/通断前必须断电**（拔掉电池），否则可能烧表
2. 测电压时表笔别同时碰到正负极造成短路
3. 黑笔永远插 COM，红笔插 VΩmA
4. 18650 串联别短路（电流大很危险），杜邦线裸露处胶布包好
5. 量 L298N 时最好先只接电池、不接电机和 ESP32，一步步来
